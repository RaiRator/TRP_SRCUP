# 랜덤 선곡 — 목표 뽑기 원리

태고의 달인 단위도장 기준을 바탕으로, 뽑힌 곡의 난이도와 내 단위를 비교해 가/불가 목표를 자동으로 산출합니다.

## 기본 개념

- **적합격 / 금합격**: 각 단위 표에는 두 기준값이 있습니다. 적합격은 단위 취득의 최소 문턱, 금합격은 완벽 수행에 가까운 값입니다.
- **적OO단 / 금OO단**: "적합격을 취득한 실력"과 "금합격까지 취득한 실력"을 별도로 선택합니다. 금단위는 적단위보다 한 단계 위 실력으로 취급됩니다.
- **상황 분류**: 뽑힌 곡을 선택 단위 기준과 비교해 5가지로 나눕니다 — 같음 / 쉬움 / 매우쉬움 / 어려움 / 클리어(완주만 목표).

## 단위 인증 기준

| 단위 | 인증 기준 |
|---|---|
| 초단 · 2단 | 레벨 6~7 |
| 3단 · 4단 | 레벨 7~8 |
| 5단 · 6단 | 레벨 8 |
| 7단 · 8단 | 레벨 8~9 |
| 9단 | 레벨 9 |
| 10단 | 10레벨 중 "중상" 등급 |
| 현인 | 10레벨 중 "상" (표기: 10상) |
| 명인 | 10레벨 중 "최상" (표기: 10최상) |
| 초인 | 10레벨 중 "졸업" |
| 달인 | 10레벨 중 "졸업+" |

## 클리어 모드 (완주 자체가 목표)

선택 단위로는 판정 목표를 논하기 무의미할 만큼 어려운 곡이 뽑히면, 가/불가 대신 "클리어"만 표시합니다.

| 단위 | 발동 조건 |
|---|---|
| 초단~4단 | 레벨 9 이상 |
| 5단·6단 | 레벨 10 (등급 무관 전부) |
| 7단 | 레벨 10 중 등급 "중" 이상 |
| 8단 | 레벨 10 중 등급 "중상" 이상 |
| 9단 | 레벨 10 중 등급 "상" 이상 |
| 10단 | 레벨 10 중 등급 "최상+" 이상 |
| 현인 | 등급 "졸업" 이상 |
| 명인 | 등급이 정확히 "졸업+"일 때만 |
| 초인 · 달인 | 클리어 모드 없음 (이미 최상단) |

## 매우쉬움 구간 (초엄격 판정)

선택 단위 기준보다 훨씬 쉬운 곡이 뽑히면, "쉬움"보다 한 단계 더 타이트하게 잡습니다. 적/금 구분 없이 동일하며, 목표 범위의 하한이 0(풀콤보)까지 열립니다.

| 단위 | 매우쉬움 기준 (이하) |
|---|---|
| 8단 | 레벨 6 |
| 9단 | 레벨 6 |
| 10단 | 레벨 7 |
| 현인 | 레벨 8 |
| 명인 | 레벨 8 |
| 초인 | 레벨 9 |
| 달인 | 레벨 9 |

> 초단~7단은 이 구간이 없습니다.

## 목표 산출 공식

### 적단위 (적합격 취득자)

| 상황 | 가(오차) 범위 | 불가 개수 범위 |
|---|---|---|
| 같음 | 적합격 ~ 적합격×1.5 | 0 ~ 적합격불가 |
| 쉬움 | 금합격 ~ 적합격 | 0 ~ 금합격불가 |
| 매우쉬움 | 0 ~ 적합격 | 0 ~ 금합격불가 |
| 어려움 | 적합격 ~ 적합격×2 | 금합격불가 ~ 적합격불가×2 |
| 클리어 | "-" 표시 | "클리어" 표시 |

### 금단위 (금합격 취득자)

금단위는 이미 적단위 인증 기준을 넘어선 실력이므로, "같음"·"어려움"의 기준이 적단위보다 한 단계 어렵게 잡힙니다. "쉬움"·"매우쉬움"은 적단위와 동일한 공식을 씁니다.

| 상황 | 가(오차) 범위 | 불가 개수 범위 |
|---|---|---|
| 같음 | 금합격 ~ 적합격x1.5 | 0 ~ 금합격불가 |
| 쉬움 | 금합격 ~ 적합격 (적단위와 동일) | 0 ~ 금합격불가 |
| 매우쉬움 | 0 ~ 적합격 (적단위와 동일) | 0 ~ 금합격불가 |
| 어려움 | 적합격 ~ 적합격×1.5 | 금합격불가 ~ 적합격불가×2 |
| 클리어 | "-" 표시 | "클리어" 표시 |

### 인단위 (현인~달인) 전용 처리

시트에 "미만"(3곡 기준보다 쉬움) / "3곡"(정확히 인증 기준) 두 값만 있습니다. 이 두 값도 적합격/금합격 쌍으로 취급해 위와 같은 공식을 그대로 적용합니다.

- **같음** (3곡 기준과 일치): "3곡" 행의 적합격/금합격 사용
- **쉬움** (3곡보다 쉬움, 매우쉬움 경계보다는 위): "미만" 행의 적합격/금합격 사용
- **매우쉬움** (레벨이 매우쉬움 경계 이하): "미만" 행 기준 0~적합격
- **어려움** (3곡보다 어렵지만 클리어 미달): "3곡" 행 값을 초단~9단과 같은 어려움 공식에 대입

## 플레이 수

단위·상황과 무관하게 항상 1~4플레이 중 하나가 균등 랜덤으로 함께 제시됩니다.

## 예시 (9단: 적합격 40가 · 금합격 26가 · 적합격불가 3 · 금합격불가 1)

| 뽑힌 곡 | 상황 | 가 범위 | 불가 범위 |
|---|---|---|---|
| 레벨 6 이하 | 매우쉬움 | 0~40 | 0~3 |
| 레벨 7~8 | 쉬움 | 26~40 | 0~1 |
| 레벨 9 | 같음 | 40~60 | 0~1 |
| 레벨 10 (상 미달) | 어려움 | 40~80 | 1~6 |
| 레벨 10 (상 이상) | 클리어 | - | 클리어 |
