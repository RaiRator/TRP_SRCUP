# 랜덤 선곡 — 목표 뽑기 원리

태고의 달인 단위도장 기준을 바탕으로, 뽑힌 곡의 난이도와 내 단위를 비교해 가/불가 목표를 자동으로 산출합니다.


## 1. 기본 개념

1. 사용자가 자신의 "단위"(초단-10단, 현인-달인)를 선택하면, 방금 뽑힌 곡의 난이도를 그 단위의 인증 기준과 비교해 상황을 분류하고, 상황에 맞는 공식으로 목표(가 개수, 불가 개수)를 산출합니다.
   
2. 해당 사이트의 기능은 1~4 플레이 안에 랜덤으로 정해진 목표치를 달성해야 하는 콘텐츠를 다루며, 단위 이론치를 평균 판정 수준으로 잡고, 초견-일발 성과를 기준으로 수치 밸런스를 조정 하였습니다.

- **적합격 / 금합격**: 각 단위 표에는 두 기준값이 있습니다. 적합격은 단위 취득의 최소 문턱, 금합격은 완벽 수행에 가까운 값입니다.
- **적OO단 / 금OO단**: "적합격을 취득한 실력" 또는 "금합격까지 취득한 실력" 중 하나를 선택합니다.
- **상황(6가지)**: 같음 / 쉬움 / 매우쉬움 / 어려움 / 매우어려움 / 클리어 모드로 분류합니다.
- **금단위 전역 보정**: 금단위를 선택하면, 모든 상황에서 산출된 가(오차)의 최소·최대값에 공통으로 **×0.7**이 곱해집니다. 불가 개수에는 이 보정이 적용되지 않습니다.

## 2. 단위 인증 기준 (범위 방식)

초단-9단은 레벨 범위를 그대로 씁니다. 10단과 인단위(현인-달인)는 2단계 폭의 범위로 인증 기준을 잡습니다. 

| 단위 | 인증 기준 |
|---|---|
| 초단 · 2단 | 레벨 6~7 |
| 3단 · 4단 | 레벨 7~8 |
| 5단 · 6단 | 레벨 8 |
| 7단 · 8단 | 레벨 8~9 |
| 9단 | 레벨 9 |
| 10단 | 10레벨 중 "중하~중" 등급 |
| 현인 | 10레벨 중 "중~중상" 등급 |
| 명인 | 10레벨 중 "중상~상" 등급 |
| 초인 | 10레벨 중 "상~최상" 등급 |
| 달인 | 10레벨 중 "최상~최상+" 등급 |

## 3. 상황 분류

### 3-1. 클리어 모드 (완주 자체가 목표)

선택 단위로는 판정 목표를 논하기 무의미할 만큼 어려운 곡이 뽑히면, 가/불가 숫자 대신 "클리어(완주)"만 목표로 제시합니다.

| 단위 | 클리어 모드 발동 조건 |
|---|---|
| 초단~4단 | 레벨 9 이상 |
| 5단·6단 | 레벨 10 (등급 무관 전부) |
| 7단 | 레벨 10 중 등급 "중" 이상 |
| 8단 | 레벨 10 중 등급 "중상" 이상 |
| 9단 | 레벨 10 중 등급 "상" 이상 |
| 10단 | 레벨 10 중 등급 "최상+" 이상 |
| 현인 | 등급 "졸업" 이상 |
| 명인 | 등급이 정확히 "졸업+"일 때만 |
| 초인 · 달인 | 클리어 모드 없음 |

### 3-2. 매우쉬움 (초엄격 판정 구간)

선택 단위 기준보다 훨씬 쉬운 곡이 뽑히면, "쉬움"보다 한 단계 더 엄격하게 잡습니다. 적/금 구분 없이 동일한 공식(0~적합격)을 적용합니다.

| 단위 | 매우쉬움 기준 (이하) |
|---|---|
| 8단 | 레벨 6 |
| 9단 | 레벨 6 |
| 10단 | 레벨 7 |
| 현인 | 레벨 8 |
| 명인 | 레벨 8 |
| 초인 | 레벨 9 |
| 달인 | 레벨 9 |

> 초단~7단은 이 구간이 없습니다.

### 3-3. 매우어려움 (신설 — 클리어 모드 바로 아래 단계)

클리어 모드 발동 등급보다 한 단계 낮은 등급이 정확히 뽑히면, "어려움"보다 더 널널한 "매우어려움" 상황으로 분류합니다. 10단과 인단위 3종(10단·현인·명인·초인)에만 존재합니다.

| 단위 | 매우어려움 등급 (정확히 일치) |
|---|---|
| 10단 | 최상 |
| 현인 | 최상+ |
| 명인 | 졸업 |
| 초인 | 졸업+ |

> 달인은 최고 단위 이기에, 매우어려움 구간이 없습니다.

### 3-4. 같음 / 쉬움 / 어려움

- **같음**: 뽑힌 곡이 선택 단위의 인증 범위 안에 있음
- **쉬움**: 인증 범위보다 쉽지만, 매우쉬움 경계보다는 위
- **어려움**: 인증 범위보다 어렵지만, 매우어려움·클리어 모드 경계에는 못 미침

## 4. 목표 산출 공식

아래 공식은 항상 "적단위 기준"으로 먼저 계산됩니다. 선택한 단위가 금단위라면, 산출된 가(오차)의 최소·최대값에 공통으로 ×0.7을 곱하는 후처리를 거칩니다. 불가 개수는 이 보정 대상이 아닙니다.

### 4-1. 가(오차) 범위 — 적단위 기준

| 상황 | 숫자단위(초단~10단) | 인단위(현인~달인) |
|---|---|---|
| 같음 | 적합격 ~ 적합격×1.5 | 적합격×1.5 ~ 적합격×2.0 |
| 쉬움 | 금합격 ~ 적합격 | 금합격 ~ 적합격×1.5 |
| 매우쉬움 | 0 ~ 적합격 | 0 ~ 적합격 |
| 어려움 | 적합격 ~ 적합격×2 | 적합격×1.5 ~ 적합격×3.0 |
| 매우어려움 | (10단만 해당) 적합격×2.0 ~ 적합격×5.0| (달인은 해당X) 적합격×2.0 ~ 적합격×5.0 |
| 클리어 | "-" 표시 | "-" 표시 |

> 금단위를 선택한 경우, 위 표에서 나온 최소·최대값 각각에 ×0.7을 곱한 값이 최종 가(오차) 범위가 됩니다.

### 4-2. 불가 개수 범위 (전역 통일 — 숫자단위/인단위, 적단위/금단위 모두 동일)

| 상황 | 불가 개수 범위 |
|---|---|
| 같음 | 0 ~ 적합격불가×2 |
| 쉬움 | 0 ~ 금합격불가 |
| 매우쉬움 | 0 ~ 금합격불가 |
| 어려움 | 금합격불가 ~ 적합격불가×3 |
| 매우어려움 | 금합격불가 ~ 적합격불가×3 (어려움과 동일) |
| 클리어 | "클리어" 표시 |

> 불가 개수는 금단위 여부와 무관하게 항상 이 공식 그대로 적용됩니다 (70% 보정 없음).

### 4-3. 참조 표 선택 규칙

- **10단**: 같음/어려움/매우어려움은 시트의 "10단(3곡)" 표를, 쉬움/매우쉬움은 "10단(1곡)" 표를 사용합니다.
- **현인~달인**: 같음은 "3곡" 행, 쉬움·매우쉬움은 "미만" 행을 사용합니다. 어려움·매우어려움은 "3곡" 행의 값을 기준으로 위 4-1의 공식에 대입합니다.

## 5. 3분할 표시 (쉬움 / 적정 / 어려움)

가(오차)·불가 개수·플레이 수 각각이 뽑힌 값에 따라 세 단계로 나뉘어 색으로 표시됩니다. "숫자가 작을수록 어렵다"는 원칙을 따릅니다 (허용 오차가 적을수록, 시도 기회가 적을수록 달성이 어렵기 때문).

| 구분 | 판정 기준 | 색상 |
|---|---|---|
| 가/불가 | 뽑힌 값이 min~max 구간의 하위 1/3 | 어려움 (빨강) |
| 가/불가 | 뽑힌 값이 min~max 구간의 중위 1/3 | 적정 (파랑) |
| 가/불가 | 뽑힌 값이 min~max 구간의 상위 1/3 | 쉬움 (초록) |
| 플레이 수 | 1플레이 | 어려움 (빨강) |
| 플레이 수 | 2~3플레이 | 적정 (파랑) |
| 플레이 수 | 4플레이 | 쉬움 (초록) |

## 6. 특수 케이스

### 6-1. 동더풀콤보 (가=0)

산출 범위상 가(오차)가 0(전량)으로 뽑히면, 불가도 강제로 0(풀콤보)으로 맞추고 가/불가 카드 둘 다 움직이는 무지개색으로 표시됩니다. 매우쉬움 상황(최소값이 0인 유일한 경우)에서만 나올 수 있습니다.

### 6-2. 황금 풀콤보 (불가=0, 가는 0이 아님)

가는 정상적으로 나왔지만 불가만 0(풀콤보)으로 뽑힌 경우, 불가 카드만 황금색으로 강조되어 표시됩니다.

### 6-3. 개인차 / 등급없음 처리

9·10레벨 곡인데 서열등급이 "개인차"이거나 시트에 등급이 등록되지 않은 경우, 오차·불가 기준을 판단하기 어렵고 오류 소지가 있어 목표 뽑기 버튼이 비활성화되고 안내 문구가 표시됩니다.

## 7. 플레이 수

단위·상황과 무관하게 항상 1~4플레이 중 하나가 균등 랜덤으로 함께 제시됩니다.

## 8. 예시로 확인하기

### 8-1. 9단 (숫자단위, 적합격 40가 · 금합격 26가 · 적합격불가 3 · 금합격불가 1)

| 뽑힌 곡 레벨/등급 | 상황 | 가 범위 (적단위) | 불가 범위 |
|---|---|---|---|
| 레벨 6 이하 | 매우쉬움 | 0 ~ 40 | 0 ~ 1 |
| 레벨 7~8 | 쉬움 | 26 ~ 40 | 0 ~ 1 |
| 레벨 9 | 같음 | 40 ~ 60 | 0 ~ 6 |
| 레벨 10 (중상 이하) | 어려움 | 40 ~ 80 | 1 ~ 9 |
| 레벨 10 (상 이상) | 클리어 | - (표시 없음) | 클리어 |

### 8-2. 현인 (인단위, 3곡: 적합격 24가 · 금합격 16가 · 적합격불가 2 · 금합격불가 0)

| 뽑힌 곡 등급 | 상황 | 가 범위 (적단위) | 불가 범위 |
|---|---|---|---|
| 레벨 8 이하 | 매우쉬움 | 0 ~ 12 | 0 ~ 0 |
| 레벨 9 / 등급 하~하위 | 쉬움 | 8 ~ 12 | 0 ~ 0 |
| 중 ~ 중상 | 같음 | 36 ~ 48 | 0 ~ 4 |
| 상 ~ 최상 | 어려움 | 36 ~ 72 | 0 ~ 6 |
| 최상+ | 매우어려움 | 48 ~ 120 | 0 ~ 6 |
| 졸업 이상 | 클리어 | - (표시 없음) | 클리어 |

> 금단위(예: 금현인)를 선택하면, 위 표의 가 범위 최소·최대에 각각 ×0.7을 곱한 값이 최종 목표가 됩니다.
