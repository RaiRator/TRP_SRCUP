# 랜덤 선곡 — 태고의 달인 랜덤 선곡 & 목표 뽑기

구글 시트에 등록된 곡 데이터를 기반으로 랜덤 선곡하고, 단위도장 기준의 목표(가/불가 개수)까지 함께 뽑아주는 웹 도구입니다. 설치 없이 브라우저에서 바로 사용할 수 있고, 모바일에서는 PWA로 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

🔗 **바로가기**: https://rairator.github.io/TRP_SRCUP/

## 주요 기능

### 🎵 랜덤 선곡
- 오니/우라, 어려움(모두난이도) 풀 선택
- 레벨(1~10), 카테고리, 서열등급(8·9·10렙) 다중 필터
- 커스텀 선곡풀: 원하는 곡만 담아서 그 안에서만 뽑기 (켜고 끌 수 있음)
- 제외 목록: 특정 곡을 항상 제외 (필터·커스텀풀과 독립적으로 항상 적용)

### 🎯 목표 뽑기 (단위도장 기반)
- 초단~10단, 현인~달인(인단위) 단위 선택, 적합격/금합격 구분
- 뽑힌 곡 난이도에 따라 같음·쉬움·매우쉬움·어려움·매우어려움·클리어 6단계 자동 판정
- 가/불가/플레이 수 난이도를 3분할(쉬움·적정·어려움)로 색상 표시
- 개인차·미등록 등급 곡은 목표 뽑기 자동 비활성화

### 🌐 다국어 지원
한국어 / English / 日本語 전환 지원

### 📱 PWA
홈 화면에 추가해 앱처럼 실행, 오프라인에서도 기본 화면 유지

## 사용 방법
1. 사이트 접속 후 레벨/카테고리/서열등급 필터 설정 (또는 커스텀 선곡풀 구성)
2. 뽑기 버튼으로 곡 선정
3. 본인 단위를 선택하면 해당 곡 기준 목표(가/불가 개수, 추천 플레이 수)를 함께 뽑을 수 있음

## 데이터 출처
곡 데이터와 목표치 기준은 구글 시트로 관리되며, 시트 업데이트 시 사이트에 자동 반영됩니다.

## 목표 뽑기 — 밸런스 산출 공식

### 기본 개념

- **적합격 / 금합격**: 단위 표에는 두 기준값이 있습니다. 적합격은 단위 취득의 최소 문턱, 금합격은 완벽 수행에 가까운 값입니다.
- **적OO단 / 금OO단**: "적합격을 취득한 실력" 또는 "금합격까지 취득한 실력" 중 하나를 선택합니다.
- **상황(6가지)**: 같음 / 쉬움 / 매우쉬움 / 어려움 / 매우어려움 / 클리어 모드로 분류합니다.
- **금단위 전역 보정**: 금단위를 선택하면, 모든 상황에서 산출된 가(오차)의 최소·최대값에 공통으로 **×0.7**이 곱해집니다. 불가 개수에는 이 보정이 적용되지 않습니다.

### 단위 인증 기준

| 단위 | 인증 기준 |
|---|---|
| 초단 · 2단 | 레벨 6~7 |
| 3단 · 4단 | 레벨 7~8 |
| 5단 · 6단 | 레벨 8 |
| 7단 · 8단 | 레벨 8~9 |
| 9단 | 레벨 9 |
| 10단 | 10레벨 중 "중하~중" 등급 |
| 현인 | 10레벨 중 "중~중상" 등급 |
| 명인 | 10레벨 중 "중상~상" 등급 |
| 초인 | 10레벨 중 "상~최상" 등급 |
| 달인 | 10레벨 중 "최상~최상+" 등급 |

### 클리어 모드 (완주 자체가 목표)

| 단위 | 클리어 모드 발동 조건 |
|---|---|
| 초단~4단 | 레벨 9 이상 |
| 5단·6단 | 레벨 10 (등급 무관 전부) |
| 7단 | 레벨 10 중 등급 "중" 이상 |
| 8단 | 레벨 10 중 등급 "중상" 이상 |
| 9단 | 레벨 10 중 등급 "상" 이상 |
| 10단 | 레벨 10 중 등급 "최상+" 이상 |
| 현인 | 등급 "졸업" 이상 |
| 명인 | 등급이 정확히 "졸업+"일 때만 |
| 초인 · 달인 | 클리어 모드 없음 (이미 최상단) |

### 매우쉬움 (초엄격 판정 구간)

선택 단위 기준보다 훨씬 쉬운 곡이 뽑히면, "쉬움"보다 한 단계 더 엄격하게 잡습니다.

| 단위 | 매우쉬움 기준 (이하) |
|---|---|
| 8단 | 레벨 6 |
| 9단 | 레벨 6 |
| 10단 | 레벨 7 |
| 현인 | 레벨 8 |
| 명인 | 레벨 8 |
| 초인 | 레벨 9 |
| 달인 | 레벨 9 |

> 초단~7단은 이 구간이 없습니다.

### 매우어려움 (클리어 모드 바로 아래 단계)

인단위 4종(10단·현인·명인·초인)에만 존재합니다.

| 단위 | 매우어려움 등급 (정확히 일치) |
|---|---|
| 10단 | 최상 |
| 현인 | 최상+ |
| 명인 | 졸업 |
| 초인 | 졸업+ |

> 달인은 이미 최상단(클리어 모드 자체가 없음)이라 매우어려움 구간이 없습니다.

### 가(오차) 범위 — 적단위 기준

| 상황 | 숫자단위(초단~10단) | 인단위(현인~달인) |
|---|---|---|
| 매우쉬움 | 0 ~ 적합격×1.0 | 0 ~ 적합격×1.0 |
| 쉬움 | 금합격 ~ 적합격×1.0 | 금합격 ~ 적합격×2.0 |
| 같음 | 적합격×1.0 ~ 적합격×1.5 | 적합격×1.5 ~ 적합격×3.0 |
| 어려움 | 적합격×1.0 ~ 적합격×2.0 | 적합격×2.0 ~ 적합격×4.0 |
| 매우어려움 | (해당 없음) | 적합격×3.0 ~ 적합격×5.0 |
| 클리어 | "-" 표시 | "-" 표시 |

> 금단위를 선택한 경우, 위 표에서 나온 최소·최대값 각각에 ×0.7을 곱한 값이 최종 가(오차) 범위가 됩니다.

### 불가 개수 범위 (전역 통일 — 숫자단위/인단위, 적단위/금단위 모두 동일)

| 상황 | 불가 개수 범위 |
|---|---|
| 같음 | 0 ~ 적합격불가×2 |
| 쉬움 | 0 ~ 금합격불가 |
| 매우쉬움 | 0 ~ 금합격불가 |
| 어려움 | 금합격불가 ~ 적합격불가×3 |
| 매우어려움 | 금합격불가 ~ 적합격불가×3 (어려움과 동일) |
| 클리어 | "클리어" 표시 |

> 불가 개수는 금단위 여부와 무관하게 항상 이 공식 그대로 적용됩니다 (70% 보정 없음).

### 참조 표 선택 규칙

- **10단**: 같음/어려움/매우어려움은 시트의 "10단(3곡)" 표를, 쉬움/매우쉬움은 "10단(1곡)" 표를 사용합니다.
- **현인~달인**: 같음은 "3곡" 행, 쉬움·매우쉬움은 "미만" 행을 사용합니다. 어려움·매우어려움은 "3곡" 행의 값을 기준으로 위 공식에 대입합니다.

### 3분할 표시 (쉬움 / 적정 / 어려움)

가(오차)·불가 개수·플레이 수 각각이 뽑힌 값에 따라 세 단계로 나뉘어 색으로 표시됩니다. "숫자가 작을수록 어렵다"는 원칙을 따릅니다.

| 구분 | 판정 기준 | 색상 |
|---|---|---|
| 가/불가 | 뽑힌 값이 min~max 구간의 하위 1/3 | 어려움 (빨강) |
| 가/불가 | 뽑힌 값이 min~max 구간의 중위 1/3 | 적정 (파랑) |
| 가/불가 | 뽑힌 값이 min~max 구간의 상위 1/3 | 쉬움 (초록) |
| 플레이 수 | 1플레이 | 어려움 (빨강) |
| 플레이 수 | 2~3플레이 | 적정 (파랑) |
| 플레이 수 | 4플레이 | 쉬움 (초록) |

### 특수 케이스

- **동더풀콤보 (가=0)**: 가(오차)가 0(전량)으로 뽑히면, 불가도 강제로 0(풀콤보)으로 맞추고 가/불가 카드 둘 다 무지개색으로 표시됩니다. 매우쉬움 상황에서만 나올 수 있습니다.
- **황금 풀콤보 (불가=0, 가는 0이 아님)**: 불가만 0(풀콤보)으로 뽑힌 경우, 불가 카드만 황금색으로 강조 표시됩니다.
- **개인차 / 등급없음**: 9·10레벨 곡인데 서열등급이 "개인차"이거나 등록되지 않은 경우, 목표 뽑기 버튼이 비활성화됩니다.

### 플레이 수

단위·상황과 무관하게 항상 1~4플레이 중 하나가 균등 랜덤으로 함께 제시됩니다.

### 예시 — 9단 (숫자단위, 적합격 40가 · 금합격 26가 · 적합격불가 3 · 금합격불가 1)

| 뽑힌 곡 레벨/등급 | 상황 | 가 범위 (적단위) | 불가 범위 |
|---|---|---|---|
| 레벨 6 이하 | 매우쉬움 | 0 ~ 40 | 0 ~ 1 |
| 레벨 7~8 | 쉬움 | 26 ~ 40 | 0 ~ 1 |
| 레벨 9 | 같음 | 40 ~ 60 | 0 ~ 6 |
| 레벨 10 (상 미달) | 어려움 | 40 ~ 80 | 1 ~ 9 |
| 레벨 10 (상 이상) | 클리어 | - (표시 없음) | 클리어 |

### 예시 — 현인 (인단위, 3곡 기준: 적합격 24가 · 금합격 16가 · 적합격불가 2 · 금합격불가 0)

| 뽑힌 곡 등급 | 상황 | 가 범위 (적단위) | 불가 범위 |
|---|---|---|---|
| 레벨 8 이하 | 매우쉬움 | 0 ~ 12 | 0 ~ 0 |
| 레벨 9 / 등급 하~하위 | 쉬움 | 8 ~ 24 | 0 ~ 0 |
| 중 ~ 중상 | 같음 | 36 ~ 72 | 0 ~ 4 |
| 상 ~ 최상 | 어려움 | 48 ~ 96 | 0 ~ 6 |
| 최상+ | 매우어려움 | 72 ~ 120 | 0 ~ 6 |
| 졸업 이상 | 클리어 | - (표시 없음) | 클리어 |

> 금단위(예: 금현인)를 선택하면, 위 표의 가 범위 최소·최대에 각각 ×0.7을 곱한 값이 최종 목표가 됩니다.
