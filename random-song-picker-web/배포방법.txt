랜덤 선곡 - 웹 배포 안내 (PWA)
================================

이 폴더 안의 파일들(index.html, manifest.json, sw.js, icon-*.png)을
정적 파일 호스팅 서비스에 올리면, 고정된 URL 하나로 누구나 접속할 수 있고
모바일에서는 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

■ 가장 쉬운 방법: Netlify Drop
  1. https://app.netlify.com/drop 접속 (가입 없이도 가능)
  2. 이 폴더 전체를 브라우저 화면에 그대로 드래그 앤 드롭
  3. 몇 초 후 https://무작위이름.netlify.app 같은 주소가 생성됨
  4. (선택) Netlify에 가입하면 주소를 원하는 이름으로 바꾸거나,
     본인 도메인을 연결할 수 있습니다.

■ 대안: Vercel, GitHub Pages, Cloudflare Pages
  위 서비스들도 정적 파일을 그대로 올리면 동일하게 동작합니다.
  (이 프로젝트는 서버 코드가 필요 없는 순수 정적 파일이라 어디든 올라갑니다.)

■ 배포 후 확인할 것
  - 배포된 주소로 접속했을 때 곡 목록이 바로 뜨는지 확인하세요.
    (뜨지 않으면 구글 시트 공유 설정이 "링크가 있는 모든 사용자 - 뷰어"인지 확인)
  - 모바일(안드로이드 크롬)에서 접속 후 메뉴 > "홈 화면에 추가"를 누르면
    앱 아이콘이 생기고, 오프라인에서도 화면 자체는 열립니다
    (단, 곡 목록을 새로 불러오려면 인터넷 연결이 필요합니다).
  - iOS(Safari)에서도 공유 버튼 > "홈 화면에 추가"로 동일하게 아이콘이 생깁니다.

■ 시트를 나중에 바꾸고 싶을 때
  index.html 안에서 아래 두 줄을 찾아 값을 바꾸고 다시 배포하면 됩니다.
    const FIXED_SHEET_ID = '1yz7bsPZrjUzCPubB-2gJbksWnlL65bbd';
    const FIXED_SHEET_GID = '1323631796';
  또는 배포된 주소 뒤에 ?admin=1 을 붙여서 접속하면(예: https://your-site.netlify.app/?admin=1)
  화면에 "⚙ 시트 설정" 버튼이 나타나 배포를 다시 하지 않고도 그 자리에서 다른 시트로
  즉시 바꿔볼 수 있습니다. 이 관리자 모드는 URL을 아는 사람만 쓸 수 있고,
  일반 사용자에게는 설정 버튼이 보이지 않습니다.

■ 시트 데이터를 갱신했는데 반영이 안 될 때
  구글 시트 CSV는 캐시가 걸릴 수 있어 반영에 1~2분 정도 걸릴 수 있습니다.
  급하게 확인해야 하면 브라우저에서 강력 새로고침(Ctrl+Shift+R / Cmd+Shift+R)을 해보세요.
